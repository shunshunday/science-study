01 / LEARN WITH QUIZZES

クイズに答えて、理科を理解しよう。

中学理科の4分野から問題を選んで、知識を確認できます。

  1. 出題する分野を選ぶ。ホームの「クイズで学ぶ」から、化学・物理・生物・地学、または全分野を選択します。
  2. 問題を読んで答える。問題文をよく読み、表示された選択肢から正しい答えを選びます。
  3. 答えと解説を確認する。正解・不正解を確認したら、解説を読んで理由まで理解しましょう。
  4. 次の問題へ進む。「次へ」で続けて学習できます。出題が終わったら結果を確認しよう。
ポイント： なぜその答えになるのか、理由まで説明できるようになると知識が定着しやすくなります。

02 / SCIENCE TERMS

分からない言葉は、用語一覧で調べよう。

授業の予習・復習にも、クイズで間違えた問題の確認にも使えます。

  1. ホームの「理科用語一覧」へ。用語カードが並んでいる場所まで移動します。
  2. 検索欄に言葉を入力。用語名のほか、キーワードや化学式などから探せます。
  3. 分野で絞り込む。化学・物理・生物・地学のフィルターを使って探します。
  4. 意味や説明を読む。名前だけでなく、意味や使われる場面も確認しよう。

03 / FIVE-QUESTION CHALLENGE

5問チャレンジで、実力チェック。

ランダムに出題される5問に挑戦して、今の理解度を確かめよう。

  1. チャレンジする範囲を選ぶ。全分野、化学、物理、生物、地学から選択できます。
  2. ランダムな5問に回答。1問ずつ答え、正解・不正解と解説を確認します。
  3. 結果を確認する。5問中何問正解できたかを確認しよう。
  4. もう一度挑戦する。「チャレンジ終了」で範囲選択画面に戻り、別の分野にも挑戦できます。
5問チャレンジに挑戦 →
04 / BUILD YOUR CITY

「わたしの町」で、自分だけの都市をつくろう。

道路や地区、電気・水道などを整えて、都市を発展させるシミュレーションです。

  1. 「わたしの町」を開く。左側メニューから都市画面へ移動し、人口や資金、電力・水道などの状態を確認します。
  2. 道路を整備する。道路を敷いて、建物や施設をつなぎます。
  3. 地区を指定する。住宅・商業・工業などの用途を選び、地面をドラッグして地区を指定します。条件に応じて建物が自動的に成長します。
  4. ライフラインと公共サービスを整える。電力・水道・下水を確保し、消防・警察・医療・ごみ処理などの施設を整備します。
  5. 都市の様子を見ながら改善する。人口や需要、資金、住民の満足度などを確認して、足りないものを補っていこう。
覚えておこう： 地区を指定すると、条件に応じて建物が自動で建設されます。一般の建物を1棟ずつ購入して配置する方式ではありません。

05 / CITY CONTROLS

都市のカメラと建設ツールを操作しよう。

マウス左ドラッグカメラを移動
マウス右ドラッグカメラを回転
マウスホイール拡大・縮小
キーボードの矢印キーカメラを前後左右に移動

建設するときの基本

  1. 建設カテゴリを選ぶ。道路・地区・電力・水道など、使いたいツールを選択します。
  2. 建設モードを確認する。建設操作を行うときは、建設モードと選択中のツールを確認してください。
  3. 地面をクリックまたはドラッグ。選んだツールに応じて道路を引いたり、地区の範囲を指定したりします。
注意： カメラ操作と建設操作を混同しないよう、画面下の選択中ツールを確認しよう。
06 / ACCOUNT & SAVE

ログインなしでも、すぐに遊べる。

クイズ・理科用語・5問チャレンジ・わたしの町は、アカウント登録をしなくても利用できます。

  1. そのまま遊び始める。ホームからクイズを解いたり、用語を調べたり、町づくりを始めたりできます。
  2. ゲストの資金と都市データ。ゲストの資金や都市の建物・道路などは、利用中のブラウザに保存されます。同じブラウザで再び開くと続きから遊べます。
  3. アカウントを使う場合。ログインすると、プロフィールやランキングを利用でき、都市データや資金をクラウドで保存して別の端末でも引き継げます。
覚えておこう： ログインは必須ではありません。ゲストデータはブラウザのデータを消去すると失われるため、長く保存したい場合はアカウントを利用してください。

08 / HELP

うまく動かないときは。

  • 画面が更新されない：再読み込みしてください。反映されない場合は Ctrl + F5 を試してください。
  • ログインできない：クイズや町づくりはログインなしでも遊べます。プロフィールなどを使うときだけログインしてください。
  • 都市が保存されない：ゲストの都市は同じブラウザに自動保存されます。別の端末へ引き継ぐ場合はログインしてください。
  • 操作が分からない：このページの該当項目を読み直してください。
