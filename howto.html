01 / LEARN WITH QUIZZES

クイズに答えて、科学を理解しよう。

中学科学の4分野から問題を選んで、知識を確認できます。

  1. 出題する分野を選ぶ。ホームの「クイズで学ぶ」から、化学・物理・生物・地学、または全分野を選択します。
  2. 問題を読んで答える。問題文をよく読み、表示された選択肢から正しい答えを選びます。
  3. 答えと解説を確認する。正解・不正解を確認したら、解説を読んで理由まで理解しましょう。
  4. 次の問題へ進む。「次へ」で続けて学習できます。出題が終わったら結果を確認しよう。
ポイント： なぜその答えになるのか、理由まで説明できるようになると知識が定着しやすくなります。

02 / SCIENCE TERMS

分からない言葉は、用語一覧で調べよう。

授業の予習・復習にも、クイズで間違えた問題の確認にも使えます。

  1. ホームの「科学用語一覧」へ。用語カードが並んでいる場所まで移動します。
  2. 検索欄に言葉を入力。用語名のほか、キーワードや化学式などから探せます。
  3. 分野で絞り込む。化学・物理・生物・地学のフィルターを使って探します。
  4. 意味や説明を読む。名前だけでなく、意味や使われる場面も確認しよう。

03 / FIVE-QUESTION CHALLENGE

5問チャレンジで、実力チェック。

ランダムに出題される5問に挑戦して、今の理解度を確かめよう。

  1. チャレンジする範囲を選ぶ。全分野、化学、物理、生物、地学から選択できます。
  2. ランダムな5問に回答。1問ずつ答え、正解・不正解と解説を確認します。
  3. 結果を確認する。5問中何問正解できたかを確認しよう。
  4. もう一度挑戦する。「チャレンジ終了」で範囲選択画面に戻り、別の分野にも挑戦できます。

06 / ACCOUNT & SAVE

学習の記録を保存しよう。

クイズや科学用語の学習は、ログインしなくても始められます。獲得した所持金や学習時間を長く残したい場合は、アカウントを活用しましょう。

  1. ゲストとして遊ぶ。ログインせずにクイズへ挑戦できます。ゲストで獲得した所持金（$）は、利用中のブラウザに保存されます。
  2. アカウントで記録を保存する。アカウントにログインすると、所持金や学習時間などの対応データがオンラインに保存され、別の端末からも引き継いで利用できます。
  3. 別の端末で続ける。同じアカウントでログインしてください。ゲストのブラウザ内データは、自動では別の端末へ移りません。
大切なこと： ブラウザの閲覧データやサイトデータを削除すると、ゲストの記録が失われることがあります。大切な記録はアカウントで保存しましょう。

08 / START AGAIN

もう一度、最初の問題から挑戦。

新しい問題に挑戦したいときは、ホームのクイズから分野を選び直してください。

  • クイズをやり直す：ホームへ戻り、挑戦したい分野を選ぶと新しい問題に取り組めます。
  • 記録について：クイズを選び直しても、保存済みの所持金やアカウント情報は初期化されません。
  • すべての記録を消したい場合：現在、学習データや所持金などをまとめて初期化する「最初から遊ぶ」機能はありません。アカウント削除は取り消せないため、記録のリセット目的では行わないでください。
