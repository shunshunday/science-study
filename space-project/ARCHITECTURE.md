# Space Program 3D

対象: 初代 Kerbal Space Program を参考にした独自のブラウザ3D宇宙開発シミュレーション。

## ファイル
- `index.html`: 宇宙センター/組立/飛行画面のUI
- `style.css`: UIレイアウトとHUD
- `game.js`: Three.jsシーン、パーツモデル、機体状態、飛行物理、軌道表示値、保存

## 現在の実装
- Three.jsによる3D宇宙センター施設と3Dロケットパーツ
- パーツ追加、機体重量/推力/燃料/Δvの概算、機体保存/読込
- 発射、スロットル、姿勢入力、ステージグループ、燃料消費
- 中心天体の逆二乗重力、速度依存空気抵抗、慣性、二体問題に基づく近点/遠点の計算
- 飛行HUD、科学ポイントの簡易加算

## 拡張時の境界
次の段階で `game.js` を `craft/`（パーツ定義・接続グラフ・ステージ）、`physics/`（固定刻み積分・推進・大気・重力・熱）、`orbit/`（軌道要素・予測・マニューバ）、`world/`（天体・地形・大気）、`ui/`（VAB・NavBall・HUD・マップ）、`career/` に分割する。飛行計算は固定時間刻みで実行し、描画とは独立させる。

## 未実装・要改善
ドラッグ&ドロップ接続、対称配置、実際のデカプラーによる機体分割、正確な燃料流路とエンジン点火順、空力安定性、姿勢制御/SAS/RCS、回転する天体と大気層、軌道予測線/マニューバノード、月・惑星・着陸地形、再突入熱、ドッキング、科学/契約/技術ツリー。現状の物理は初期基盤で、原作相当の精度や完成度には達していない。
