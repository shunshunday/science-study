# Space Program — architecture

初代 Kerbal Space Program の組立・飛行・軌道力学を参考にした、独自実装のブラウザ3Dゲーム。

## 現在のファイル
- `index.html`: 宇宙センター、組立、研究、契約、飛行HUD
- `style.css`: UIレイアウトとHUD
- `game.js`: Three.jsの3Dシーン、パーツモデル、組立画面、入力、飛行状態とUI接続
- `physics/orbital.js`: 二体問題、逆二乗重力、大気密度、RK4積分、軌道要素、ロケット方程式

## 単位系と物理
- ワールド座標・速度は km / km/s。Kerbin相当の半径600 km、標準重力パラメータ3531.6 km³/s²を使用。
- エンジン推力は kN、質量・推進剤は kg、比推力は秒。推力加速度と抗力はSI単位からワールド単位へ変換。
- 固定刻み1/120秒でRK4積分。重力、指数大気モデル、速度依存抗力、推力、燃料流量を更新。
- 近点・遠点・離心率・軌道長半径・傾斜角を状態ベクトルから計算。
- 液体エンジンは液体タンク、固体ブースターは自身の推進剤を消費する。

## 実装済みの基礎
3D宇宙センター、3Dパーツ、機体の縦積み、ステージグループ、保存/読込、発射、スロットル、姿勢入力、SAS/RCS切替UI、NavBall方位表示、軌道HUD、燃料消費、地表衝突判定。

## 拡張設計
次は `craft/assembly.js`（アタッチ点・対称配置・ドラッグ配置）、`physics/rigid-body.js`（角運動量・慣性テンソル・接続剛性）、`physics/aerodynamics.js`（部品ごとの揚力/抗力・圧力中心）、`orbit/prediction.js`（軌道線・マニューバノード）、`world/celestial-bodies.js`（天体・自転・大気・地表）に分離する。

## まだ完成していない機能
部品の自由なアタッチ/分離、正確な燃料配管、慣性テンソルを用いた剛体姿勢物理、空力安定性、SAS/RCSの実制御、再突入熱、軌道予測線、マニューバノード、月面着陸、ドッキング、科学・契約・技術ツリー。現在の物理は二体問題の基礎であり、原作と同じ完成度ではない。
