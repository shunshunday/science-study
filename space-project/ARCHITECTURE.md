# Space Program — architecture

初代 Kerbal Space Program の組立・飛行・軌道力学を参考にした、独自実装のブラウザ3Dゲーム。

## 現在のファイル
- `index.html`: 宇宙センター、格納庫型組立画面、検索/分類/並べ替え対応パーツカタログ、研究、契約、飛行HUD
- `style.css`: UIレイアウトとHUD
- `game.js`: Three.jsの3Dシーン、宇宙センター/格納庫、組立画面、パーツカタログの検索・分類・ソート、入力、飛行状態とUI接続。旧4種の汎用デモ部品は撤去し、保存済み機体IDは名前付きパーツへ移行。
- `parts-models.js`: 独自制作のThree.jsモデル生成ライブラリ。組立画面のプレビューと機体本体が同じモデル生成関数を共有。ポッド、プローブ、タンク、エンジン、翼、パラシュート、電力/科学装備、ドッキング、貨物、熱防護、着陸脚、採掘/ISRU、ロボット機構、回転翼などを形状別に実装。公式KSPのメッシュ/テクスチャは含まない。
- `parts-inventory.js`: ストック/DLC/非表示レガシー候補をまとめた277行の追加カタログデータ。重複排除後のゲーム内カタログは約435点。出典表示と暫定値ラベルを付ける。
- `KSP1_STOCK_PARTS_EXPANSION.json`, `KSP1_DLC_PARTS_CANDIDATES.json`, `KSP1_LEGACY_STOCK_PARTS.json`: ストック169、DLC97、非表示レガシー11の候補台帳。
- `KSP1_PARTS_MODEL_AUDIT.json`: 元の128登録パーツの照合監査。124件は候補一致、4つの汎用プレースホルダーはライブカタログから撤去。
- `export-ksp-part-configs.ps1`: Windows標準PowerShellでユーザーのKSPインストールから本体/DLCのpart.cfgを読み取り、ID・質量・価格・ノード・リソース・モジュールをJSON/CSVへ出力する。モデル/テクスチャはコピーしない。
- `physics/orbital.js`: 二体問題、逆二乗重力、大気密度、RK4積分、軌道要素、ロケット方程式
- `physics/aerodynamics.js`: 機体姿勢・迎角・部品投影面積に基づく抗力、フィン揚力、パラシュート抗力

## 単位系と物理
- ワールド座標・速度は km / km/s。Kerbin相当の半径600 km、標準重力パラメータ3531.6 km³/s²を使用。
- エンジン推力は kN、質量・推進剤は kg、比推力は秒。推力加速度と抗力はSI単位からワールド単位へ変換。
- 固定刻み1/120秒でRK4積分。重力、指数大気モデル、姿勢・迎角・機体部品の投影面積に応じた抗力、フィン揚力、推力、燃料流量を更新。パラシュートは P キーで、高度10 km以下かつ速度250 m/s以下の条件で展開。
- 近点・遠点・離心率・軌道長半径・傾斜角を状態ベクトルから計算。
- 液体エンジンは液体タンク、固体ブースターは自身の推進剤を消費する。

## 実装済みの基礎
3D宇宙センター、格納庫型VAB、検索・カテゴリ・ソート付きパーツ一覧（約435点）、名前と出典ラベル付き3Dプレビュー、独自モデル生成ライブラリ、右側ステージパネル、機体の縦積み、ステージグループ、保存/読込、発射、スロットル、姿勢入力、SAS/RCS切替UI、NavBall方位表示、軌道HUD、燃料消費、地表衝突判定。

## 拡張設計
次は `craft/assembly.js`（アタッチ点・対称配置・ドラッグ配置）、`physics/rigid-body.js`（角運動量・慣性テンソル・接続剛性）、`physics/aerodynamics.js`（部品ごとの揚力/抗力・圧力中心）、`orbit/prediction.js`（軌道線・マニューバノード）、`world/celestial-bodies.js`（天体・自転・大気・地表）に分離する。

## まだ完成していない機能
部品の自由なアタッチ/分離、正確な燃料配管、慣性テンソルを用いた剛体姿勢物理、圧力中心による空力トルク、SAS/RCSの実制御、再突入熱、軌道予測線、マニューバノード、月面着陸、ドッキング。現在の空力は部品種別・迎角・投影面積を使う近似モデルであり、圧縮性流体・衝撃波・部品ごとの干渉までは解いていない。


## ゲームモード・乗組員・科学
- キャリア / サイエンス / サンドボックスの3モードを実装。モードごとにセーブデータを分離。
- サンドボックスは全技術・全パーツを解放し、パーツを無料化。
- 乗組員の雇用と経験レベル訓練を追加。
- ポッド / プローブ / 科学実験装置を使い、地表・高高度大気圏・宇宙空間で状況ごとに一度だけ科学データを回収できる。

## 今後の大規模機能
惑星・衛星の複数天体系、自由接続式VAB、車両/航空機、乗組員の船外活動、ドッキング、基地・宇宙ステーション、通信ネットワーク、施設拡張、再突入熱、部品ごとの空力は未実装。


## パーツモデルの精度とデータ品質
- 約435点のカタログは、既存登録・ストック候補・DLC候補・非表示レガシー候補を重複排除して統合したもの。すべての公式1.12.5パーツを網羅したと断言できる段階ではない。
- 新規候補の多くは、正確な1.12.5 `.cfg` をまだ照合できていないため、重量・価格・寸法・推力・推進剤容量は暫定推定値。カタログカードと詳細ツールチップで暫定値を明示する。
- 3Dモデルはすべて独自のThree.js形状近似であり、公式KSPモデルの正確な複製ではない。外部の公式モデル/テクスチャは無許諾で同梱しない。
- ローカルのKSP1インストールが利用できる場合は `export-ksp-part-configs.ps1` のJSON出力を使い、各パーツの内部ID・ノード・リソース・モジュールを照合してから実装値へ反映する。
